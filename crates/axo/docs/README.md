# axo Documentation

`axo` is an embeddable, headless coding-agent harness core written in Rust across three crates: `axo-ai`, `axo-agent`, and `axo`.

This directory documents the implemented behavior and public APIs of the workspace. It lives inside the `axo` crate: this index and its four guides are compiled into the binary, written to `<AXO_DIR>/cache/docs/`, and reached at runtime through `axo://README.md`, which the `docs` system-prompt section points to.

## Reference Guides
